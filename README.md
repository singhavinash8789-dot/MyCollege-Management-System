# 🎓 MyCollege Management System

A C++-based college management system that brings student and faculty services together in one platform. It combines academic management features with student profiles and social networking functionality.

## 📌 About the Project

**MyCollege Management System** is a collaborative C++ project developed by a team of six students. The goal is to create a platform where students and faculty members can interact and manage various college-related activities.

The project demonstrates the practical implementation of Object-Oriented Programming, Data Structures, and core C++ concepts.

## ✨ Features

### 👨‍🏫 Faculty Portal
- Student management
- Attendance management
- Student performance management
- Sorting and updating student records
- Viewing recently added students
- Managing student requests through a queue

### 👨‍🎓 Student Portal
- Student registration and profile management
- Profile searching
- Community feed and posts
- Blog functionality
- User authentication
- Searching for other users
- Sending and managing connection requests

### 🤝 User & Connection Management
- Student and faculty user management
- Registration and login functionality
- Input validation
- User searching
- Connection management using graph data structures
- Adjacency-list representation of connections

## 🛠️ Technologies Used

- **Language:** C++
- **Programming Concepts:** Object-Oriented Programming (OOP)
- **Data Structures:** 
  - Arrays and Vectors
  - Queues
  - Graphs
  - Adjacency Lists
  - Strings
- **Other Concepts:** Authentication, Input Validation, Searching, Sorting

## 🚀 Getting Started

### Prerequisites

You need a C++ compiler such as GCC or MinGW installed on your system.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/MyCollege-Management-System.git
   ```

2. Navigate to the project directory:

   ```bash
   cd MyCollege-Management-System
   ```

3. Compile the Student-Faculty Portal:

   ```bash
   g++ Student-Faculty-Portal.cpp -o StudentFacultyPortal
   ```

4. Run it:

   ```bash
   ./StudentFacultyPortal
   ```

5. To compile and run the User-Connection System separately:

   ```bash
   g++ User-Connection-System.cpp -o UserConnectionSystem
   ./UserConnectionSystem
   ```

*Note: These are two separate C++ programs and should be compiled and executed independently.*
